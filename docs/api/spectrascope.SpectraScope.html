SpectraScope([X, y, fnX, fny, specnames, ...])

The main SpectraScope class encompasses all data loading, feature generation, model training, and model evaluation.
class spectrascope.SpectraScope.SpectraScope(X=None, y=None, fnX=None, fny=None, specnames=[], yname='', random_seed=None, save_path=None)[source]¶

Bases: object

The main SpectraScope class encompasses all data loading, feature generation, model training, and model evaluation.

Can load X, y via an array or file path. If file path, will try to infer file type.

Data will be referred to as “spectrums” but can be any 1D array like data.

Parameters:

  • X (arr, optional) – Input X. Defaults to None.

  • y (arr, optional) – Input y. Defaults to None.

  • fnX (str, optional) – Input X file path. Defaults to None.

  • fny (str, optional) – Input y file path. Defaults to None.

  • specnames (list, optional) – Names of different spectra that have loaded, if loading multiple modalities. Defaults to [].

  • yname (str, optional) – Name of yprediction. Defaults to “”.

  • random_seed (int, optional) – Random seed for splitting data and training. Suggested to set a random seed to keep same splits when comparing across models. Defaults to None.

  • save_path (str, optional) – Path for saving results. Defaults to None (saves to /examples/models).

transform_feature(feat, degree=2, interaction=True, trans_type='all', all_pos_y=True, additional_naming='')[source]¶

Adds new attribute of polynomial etc. transformations of already generated features.

Uses _feature_trans function from regression_models in SPA v1.4.1. This version is key to avoid errors. Attribute of array is {feat}_trans{additional_naming}. Attribute of names of transformations is {feat}_trans_names{additional_naming}.

Parameters:

  • feat (str) – Feature attribute to transform. Will transform test if exists. e.g. “spec1_pointwise_features”

  • degree (int, optional) – Degree of polynomial transformations. Must be in [1,2,3]. Default 2

  • interaction (bool, optional) – _description_, by default True

  • trans_type (str in {'all', 'poly', 'simple_interaction'}, optional, default "all") – Whether to include all transforms (polynomial, log, sqrt, inverse) only polynomial transform, or just interaction terms.

  • all_pos_y (bool, optional, default=True) – Whether all entries in the data are positive or also contain some negative entries. This is done to avoid taking sqrt(k) for some k<0.

  • additional_naming (str, optional, default "") – Additional naming for final feature.

See also

regression_models._feature_trans
