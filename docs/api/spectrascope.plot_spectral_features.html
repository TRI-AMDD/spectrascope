spectrascope.plot_spectral_features.plot_spectral_features_matplotlib(xaxis, raw, selected_features, ax=None, zoom=0.1, plot_raw=True, print_centers=False)[source]¶

Plot spectral features using matplotlib with annotated representative images.

Parameters:

  • xaxis (np.ndarray) – Array representing the x-axis values of the spectrum (e.g., energy or wavelength).

  • raw (np.ndarray) – The raw intensity values of the spectrum corresponding to xaxis.

  • selected_features (list or np.ndarray) – List of indices of selected features to annotate on the plot.

  • ax (matplotlib.axes.Axes, optional) – Matplotlib axis object to plot on. If None, a new axis will be created.

  • zoom (float, optional) – Zoom factor for displaying the annotated images. Default is 0.1.

  • plot_raw (bool, optional) – Whether to plot the raw spectrum as a black line. Default is True.

  • print_centers (bool, optional) – If True, prints the center x-values and corresponding selected feature indices.

Returns:

ax – The axis object containing the generated plot.

Return type:

matplotlib.axes.Axes

Notes

This function overlays annotated images (e.g., icons of feature types) at the bin centers of selected spectral features, using images from static files. The images corresponding to feature types are matched using a pre-defined mapping. The function assumes the existence of static images for each feature type in the ‘../app/static/’ directory.

Example

>>> plot_spectral_features_matplotlib(xaxis, spectrum, selected_features, ax=ax, zoom=0.03)
