spectrascope.utils.entropy(p0, p1)[source]¶

Calculate entropy of a random variable.

Entropy of a random variable is the avarage level of “information”, “surprise”, or “uncertainty” inherent in the variable’s possible outcomes.

Parameters:

  • p0 (float) – The probability of choosing class 1.

  • p1 (float) – The probability of choosing class 2.

Returns:

entropy of random variable.

Return type:

float
