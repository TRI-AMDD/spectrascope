spectrascope.utils.predict_LCEN(model, X)[source]#

Predict using the parameters of a fitted LCEN model.

Uses the stored model_params (coefficients and intercept) from a fitted LCEN model (from SPA) to compute predictions for a given design matrix X. In model_params, entries like “x0”, “x1” indicate which feature indices have nonzero coefficients; all other coefficients are zero. The coefficient vector length matches X.shape[1].

Parameters:

  • model (dict) – Fitted LCEN model from main.SPA. Must contain key “model_params”.

  • X (np.ndarray) – Design matrix, shape (n_samples, n_features). Must have the same number of features as the model was trained on, in the same order.

Returns:

y_pred – Predicted values, shape (n_samples,).

Return type:

np.ndarray

Notes

Linear-in-X models only. If model_params contain polynomial or other transformed terms (e.g. “x0^2”), NotImplementedError is raised. The caller must pass X in the same scale/preprocessing as at training (e.g. same StandardScaler); the LCEN dict does not store scaler parameters.
