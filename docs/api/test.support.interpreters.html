The receiving end of a cross-interpreter channel.

recv(*, _sentinel=<object object>, _delay=0.01)[source]#

Return the next object from the channel.

This blocks until an object has been sent, if none have been sent already.

recv_nowait(default=<object object>)[source]#

Return the next object from the channel.

If none have been sent then return the default if one is provided or fail with ChannelEmptyError. Otherwise this is the same as recv().

class test.support.interpreters.SendChannel[source]#

Bases: _ChannelEnd

The sending end of a cross-interpreter channel.

send(obj)[source]#

Send the object (i.e. its data) to the channel’s receiving end.

This blocks until the object is received.

send_nowait(obj)[source]#

Send the object to the channel’s receiving end.

If the object is immediately received then return True (else False). Otherwise this is the same as send().
