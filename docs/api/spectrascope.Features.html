Spectral Features class used by SpectraScope main class to generate features on datasets.

A class that creates feature vectors extracted from 1D array data. Current features developed for spectral data, but could be applied to any 1D data. Every feature generation method assumes you want to perform on the interpolated spectra, so looks for interpolated data before performing operations on the original data. Most featurizer functions are vectorized and can accept multiple samples at once.

Parameters:

  • energies (array-like) – x axis (energy, time). shape: (n_features,))

  • intensities (array-like) – y axis (intensity, current, etc). shape: (n_samples, n_features))

tsne(n_components=2, verbose=False, return_features=False, **kwargs)[source]¶

T-distributed Stochastic neighbor embedding

Converts similarities between data points to joint probabilities and tries to minimize the Kullback-Leibler divergence between the joint probabilties of the low-dimensional embedding and the high-dimensional data. t-SNE has a cost function that is not convex, i.e. with different initializations we can get different results. Recommended to apply PCA first to reduce dimensions (to ~50) then peform TSNE on the PCA features.

Parameters:

  • n_components (int, optional, default=2) – Number of components. Must be < 4.

  • verbose (bool, optional, default=False) – print progress.

  • return_features (bool, optional, default=False) – return features.

  • **kwargs (dict) – additional parameters to pass to TSNE.

tsne_features¶

tsne features shape (n_samples, n_components).

Type:

np.array

Split the data into uneven sections and perform polynomial fitting on each section.

Option to split each section into different N values and degrees. Generates polynomial_featuresN(N, degree=degree, x=x, y=y, verbose=verbose) for every N, degree on each eV range (np.array).

Parameters:

  • N_dict (dict, optional, default={0:10, 1:4, 2:5}) – the N values for each split {0:N, 1:N, 2:N}, must have len(ev_splits) + 1.

  • degree_dict (dict, optional, default={0:3, 1:5, 2:3}) – the degree values for each split {0:degree, 1:degree, 2:degree}, must have len(N_dict).

  • verbose (bool, optional, default=False) – whether to print names of attributes.

  • plot (bool, optional, default=False) – plot subsections.
